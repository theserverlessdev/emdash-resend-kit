# Support

## Questions

1. Read the [README](./README.md). The section "Troubleshooting" lists each error message.
2. Read the [FAQ](./docs/faq.md).
3. Search the [issues](https://github.com/theserverlessdev/emdash-resend-kit/issues).
4. Ask in [Discussions](https://github.com/theserverlessdev/emdash-resend-kit/discussions).

## Bugs

Open a [bug report](https://github.com/theserverlessdev/emdash-resend-kit/issues/new?template=bug_report.yml).
Include the versions, the configuration without secrets, and the exact error message.

## Feature requests

Open a [feature request](https://github.com/theserverlessdev/emdash-resend-kit/issues/new?template=feature_request.yml).
Describe the problem that you want to solve.

## Security problems

Do not open a public issue. Read [SECURITY.md](./SECURITY.md).

## Other projects

This project cannot help with these subjects:

- Problems with a Resend account, billing, or deliverability. Use <https://resend.com/help>.
- Problems with EmDash itself. Use <https://github.com/emdash-cms/emdash>.

This project is independent. It has no affiliation with Resend or Cloudflare.
